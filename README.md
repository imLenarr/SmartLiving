# SmartLiving Property

ระบบจัดการห้องเช่า สัญญา และเงินประกันด้วย Solidity และเว็บ Vite + ethers.js ใช้ MetaMask บน Sepolia Testnet

## 1. Deploy Smart Contract ใน Remix

1. เตรียม Wallet บน Sepolia 3 บัญชี ได้แก่ A (เจ้าของห้องและผู้ Deploy), B (ผู้เช่า) และ C (ผู้ชี้ขาด) แต่ละบัญชีต้องมี Sepolia ETH สำหรับค่า gas บัญชี B ต้องมียอดเพิ่มสำหรับค่าเช่าและเงินประกันด้วย
2. เปิด [Remix IDE](https://remix.ethereum.org) แล้วนำไฟล์ `contracts/SmartLiving.sol` เข้า File Explorer
3. ไปที่ **Solidity Compiler** เลือก **0.8.26** แล้วกด **Compile SmartLiving.sol**
4. ไปที่ **Deploy & Run Transactions** เลือก **Injected Provider – MetaMask** ในบางเวอร์ชันเมนูนี้แสดงชื่อ **Browser Extension** ตรวจว่า Wallet ใช้บัญชี A และเครือข่าย Sepolia
5. เลือก Contract **SmartLiving** ตั้ง **Value = 0** ใส่ Wallet ของ C ในช่อง `disputeArbitrator` แล้วกด **Deploy** และยืนยันใน MetaMask
6. เมื่อขึ้นใน **Deployed Contracts** ให้คัดลอก **Contract Address** จากรายการนั้น

## 2. เปิดหน้าเว็บใน VS Code

ติดตั้ง Node.js 20 ขึ้นไป เปิดโฟลเดอร์ `SmartLiving` ใน VS Code แล้วรันใน Terminal

```bash
npm ci
npm run dev
```

เปิด URL ที่แสดงใน Terminal (ปกติ `http://localhost:5173`) ด้วยเบราว์เซอร์ที่มี MetaMask แล้วเลือก **Sepolia** กด **เชื่อม MetaMask** วาง Contract Address และกด **บันทึกที่อยู่** หน้าเว็บจำที่อยู่ไว้ในเบราว์เซอร์

เมื่อสลับบัญชี A, B หรือ C ใน MetaMask หน้าเว็บจะโหลดสิทธิ์ของบัญชีที่เลือก หาก MetaMask ยังไม่ให้เว็บเข้าถึงบัญชีนั้น ให้กด **เชื่อม MetaMask** และอนุญาตบัญชีเพิ่ม

## 3. เดโมแบบคืนเงินตามผลตรวจห้อง

| ผู้ดำเนินการ | ขั้นตอน |
| --- | --- |
| A | ลงทะเบียนห้อง เช่น A101 ค่าเช่า 0.001 ETH เงินประกัน 0.002 ETH |
| A | เลือกห้อง สร้างสัญญาใส่ Wallet ของ B ตั้งเวลาเริ่มเป็นเวลาปัจจุบันหรือนาทีที่ผ่านมา ตั้งเวลาสิ้นสุดให้เหลือเวลาทำรายการ เช่น 15 นาที แล้วกรอกเงื่อนไข |
| A และ B | เปิดสัญญาแล้วกด **ยืนยันสัญญา** จากทั้งสองบัญชี |
| B | กด **ฝาก 0.002 ETH** แล้วกด **จ่ายค่าเช่า 0.001 ETH** ในช่วงสัญญา ตรวจรายการใน **ประวัติชำระค่าเช่า** |
| A | หลังสิ้นสุดสัญญา กด **โหลดข้อมูลล่าสุด** เปิดสัญญาแล้วกรอกผลตรวจ เช่น พบความเสียหาย เสนอหัก 0.0005 ETH และส่งให้ผู้เช่าอนุมัติ |
| B | กด **อนุมัติคืน 0.0015 ETH** แล้วกด **ถอนเข้า Wallet** |
| A | กด **ถอนเข้า Wallet** เพื่อรับค่าเช่าและยอดหักที่ได้รับอนุมัติ ยอดรวมในตัวอย่างคือ 0.0015 ETH หากยังไม่ได้ถอนค่าเช่าก่อนหน้า |

## 4. เดโมแบบมีข้อพิพาท

สร้างสัญญาใหม่และทำถึงขั้นฝากเงินประกัน หลังสัญญาสิ้นสุด A หรือ B เปิดข้อพิพาทพร้อมเหตุผลได้ทั้งก่อนและหลัง A ส่งผลตรวจ จากนั้น

1. สลับเป็นบัญชี C แล้วเลือกสัญญาที่ขึ้น **อยู่ระหว่างพิจารณา**
2. กรอกยอดหักที่อนุมัติและเหตุผล เช่น 0.0003 ETH จากยอดประกัน 0.002 ETH แล้วกด **บันทึกผลและจัดสรรเงิน**
3. B จะถอนคืนได้ 0.0017 ETH ส่วน A ถอนยอดที่อนุมัติให้หักได้ 0.0003 ETH รวมกับค่าเช่าที่ค้างถอนอยู่

## กติกาที่ใช้ในระบบ

- เงินประกันถูกพักไว้ใน Contract หลังทั้งสองฝ่ายยืนยัน ผู้เช่าต้องฝากเต็มจำนวนและฝากได้ครั้งเดียว
- ค่าเช่าแต่ละครั้งต้องตรงกับอัตราต่องวด ระบบบันทึกงวดตามลำดับที่ชำระ กำหนดวันครบกำหนดและจำนวนงวดในข้อความเงื่อนไขได้
- เงินประกันจะถูกจัดสรรหลังครบกำหนดสัญญา เมื่อผู้เช่าอนุมัติผลตรวจหรือผู้ชี้ขาดบันทึกคำตัดสิน ยอดหักสูงสุดเท่ากับเงินประกันที่พักไว้
- ผู้รับกดถอนยอดที่จัดสรรแล้วแยกกัน ผู้ชี้ขาดเป็นบัญชีที่ตั้งไว้ตอน Deploy และเป็นคนละบัญชีกับคู่สัญญา
- ห้องเปิดได้ทีละหนึ่งสัญญา คู่สัญญายกเลิกสัญญาที่ยังยืนยันไม่ครบและยังไม่ฝากเงินได้ สัญญาที่ยืนยันครบแต่ยังไม่ฝากต้องรอหมดอายุก่อนยกเลิก
- ข้อมูลบน Sepolia เปิดให้สาธารณะอ่านได้ ใช้ชื่อห้องและข้อความตัวอย่างในการเดโม
