# SmartLiving — วิธีใช้งานเว็บไซต์

**เข้าใช้งาน:** [https://imlenarr.github.io/SmartLiving/](https://imlenarr.github.io/SmartLiving/)

ระบบจัดการห้องเช่า สัญญา ค่าเช่า และเงินประกัน ผ่าน MetaMask บนเครือข่าย **Sepolia** จำนวนเงินทั้งหมดในเว็บเป็น ETH บนเครือข่ายทดสอบ

## ดาวน์โหลดเอกสาร

[ดาวน์โหลดเอกสารประกอบการใช้งาน — 66080740 วรรณษา วงค์ดี (PDF)](https://github.com/imLenarr/SmartLiving/raw/refs/heads/main/public/docs/66080740-wannasa-wongdee.pdf)

## 1. เข้าสู่เว็บไซต์และเชื่อมบัญชี

เปิดลิงก์ด้วยเบราว์เซอร์ที่ติดตั้ง MetaMask และเลือกเครือข่าย **Sepolia** เตรียมบัญชีตามหน้าที่ดังนี้

| บัญชี | ใช้ทำอะไร |
| --- | --- |
| **A — เจ้าของห้อง** | ลงทะเบียนห้อง สร้างและยืนยันสัญญา ตรวจห้อง และถอนค่าเช่า/ยอดหักที่อนุมัติ |
| **B — ผู้เช่า** | ต้องเป็น Wallet ที่ A ระบุในสัญญา ใช้ยืนยันสัญญา ฝากเงินประกัน จ่ายค่าเช่า อนุมัติยอดคืน และถอนเงินคืน |
| **C — ผู้ชี้ขาด** | ต้องเป็น Wallet ผู้ชี้ขาดที่ตั้งไว้ตอน Deploy Smart Contract ใช้พิจารณาข้อพิพาท เป็นคนละบัญชีกับ A และ B |

ชื่อ A, B และ C ใช้อ้างอิงบทบาท ไม่จำเป็นต้องตรงกับชื่อ Account 1/2/3 ใน MetaMask แต่ต้องเลือก Wallet ให้ตรงกับบทบาทของสัญญานั้น ทุกบัญชีที่ส่งธุรกรรมต้องมี Sepolia ETH สำหรับค่า gas และ B ต้องมียอดเพียงพอสำหรับเงินประกันและค่าเช่า

1. เลือกบัญชี **A** ใน MetaMask
2. กด **เชื่อม MetaMask** บนเว็บไซต์ แล้วอนุญาตให้เว็บเชื่อมบัญชี
3. ในช่อง **Contract Address บน Sepolia** ใส่ที่อยู่สัญญาที่ใช้สาธิต:

   `0x662668E533FB5025C04783C88634102C0B481BE7`

4. กด **บันทึกที่อยู่** ระบบจะจำที่อยู่ไว้ในเบราว์เซอร์นี้

หากเปลี่ยนเบราว์เซอร์หรือย้ายจาก localhost มาเว็บออนไลน์ ให้บันทึก Contract Address อีกครั้ง ทุกฝ่ายต้องใช้ที่อยู่สัญญาเดียวกัน หากใช้สัญญาที่ Deploy ใหม่ ให้ใส่ที่อยู่ใหม่แทนตัวอย่าง

ทุกครั้งที่สลับ A/B/C ให้เลือกบัญชีใน MetaMask แล้วตรวจบัญชีที่มุมบนของเว็บ หากยังไม่เปลี่ยน ให้กด **เชื่อม MetaMask** และอนุญาตบัญชีนั้น จากนั้นกด **โหลดข้อมูลล่าสุด**

## 2. A ลงทะเบียนห้องเช่า

1. ใช้บัญชี **A** เปิด **ลงทะเบียนห้องเช่า**
2. กรอก **ชื่อห้อง** เช่น `A101`
3. กรอก **ค่าเช่าต่องวด (ETH)** เช่น `0.001`
4. กรอก **เงินประกัน (ETH)** เช่น `0.002`
5. กด **ลงทะเบียนห้อง** และยืนยันธุรกรรมใน MetaMask
6. รอข้อความ **ธุรกรรมสำเร็จ** ห้องจะปรากฏใน **ห้องเช่าของฉัน**

## 3. A สร้างสัญญาเช่า

1. ใช้บัญชี **A** เลือกห้อง เช่น **#1 · A101**
2. ใน **สร้างสัญญาเช่า** กรอกข้อมูล:
   - **Wallet ผู้เช่า:** คัดลอก Address ของบัญชี **B** จาก MetaMask
   - **วันและเวลาเริ่มสัญญา (เวลาไทย):** เวลาเริ่มเช่า
   - **วันและเวลาสิ้นสุดสัญญา (เวลาไทย):** ต้องหลังเวลาเริ่มและยังไม่ถึงกำหนด
   - **เงื่อนไขที่ตกลงกัน:** เช่น “ค่าเช่า 0.001 ETH ต่องวด ตรวจห้องก่อนคืนเงินประกัน หักความเสียหายตามยอดที่ผู้เช่าอนุมัติ หากโต้แย้งให้ผู้ชี้ขาดพิจารณา”
3. กด **สร้างสัญญา** แล้วยืนยันใน MetaMask
4. เปิดสัญญาจาก **สัญญาของฉัน** ตรวจ Wallet วันเวลา ค่าเช่า เงินประกัน และเงื่อนไขให้ถูกต้อง

สำหรับเดโม ตั้งเวลาเริ่มเป็นเวลาปัจจุบันหรือนาทีที่ผ่านมา และเวลาสิ้นสุดอีกประมาณ 15–30 นาที เพื่อให้มีเวลายืนยัน ฝากเงิน และจ่ายค่าเช่าก่อนหมดสัญญา ห้องหนึ่งมีสัญญาที่ยังเปิดอยู่ได้ครั้งละหนึ่งสัญญา

## 4. A และ B ยืนยันสัญญา

1. ใช้ **A** เปิดสัญญา แล้วกด **ยืนยันสัญญา** และยืนยันใน MetaMask
2. สลับเป็น **B** เชื่อมบัญชี เปิดสัญญาเดียวกัน และอ่านเงื่อนไข
3. ใช้ **B** กด **ยืนยันสัญญา** และยืนยันใน MetaMask
4. ตรวจว่ารายการ **เจ้าของยืนยัน** และ **ผู้เช่ายืนยัน** เป็น **แล้ว** ทั้งคู่

## 5. B ฝากเงินประกันและจ่ายค่าเช่า

1. ใช้บัญชี **B** เปิดสัญญาที่ยืนยันครบแล้ว
2. กด **ฝาก 0.002 ETH** ตามยอดตัวอย่าง และยืนยันใน MetaMask ต้องทำก่อนสัญญาสิ้นสุด
3. เมื่อธุรกรรมสำเร็จ สถานะเป็น **กำลังเช่า** และเงินประกันจะพักไว้ใน Smart Contract
4. ในช่วงเวลาเริ่มถึงก่อนสิ้นสุดสัญญา กด **จ่ายค่าเช่า 0.001 ETH** ตามตัวอย่าง แล้วยืนยันใน MetaMask
5. ตรวจ **ประวัติชำระค่าเช่า** จะมีลำดับงวด ยอดชำระ และวันเวลา
6. กด **ดูบน Etherscan** หลังทำรายการ เพื่อดูธุรกรรมบนเครือข่าย

ค่าเช่าแสดงงวดตามลำดับที่จ่าย ให้ยึดกำหนดการชำระตามข้อความเงื่อนไข ระบบยังไม่บังคับวันครบกำหนดแต่ละงวดอัตโนมัติ

## 6. ตรวจห้องและคืนเงินประกัน

### A เสนอผลตรวจและยอดหัก

1. รอจนถึงเวลาสิ้นสุดสัญญา สลับเป็น **A** แล้วกด **โหลดข้อมูลล่าสุด**
2. เปิดสัญญา จะพบ **บันทึกผลตรวจห้อง**
3. ใส่ **ยอดที่เสนอหัก (ETH)** เช่น `0.0005` หากไม่หักให้ใส่ `0`
4. ใส่ **ผลตรวจและเหตุผล** เช่น “ค่าทำความสะอาดเพิ่มเติม”
5. กด **ส่งให้ผู้เช่าอนุมัติ** แล้วยืนยันใน MetaMask

### B ตรวจสอบและรับเงินคืน

1. สลับเป็น **B** เปิดสัญญา แล้วตรวจผลตรวจ ยอดเสนอหัก และยอดเสนอคืน
2. หากยอมรับ ให้กด **อนุมัติคืน 0.0015 ETH** ตามตัวอย่าง แล้วยืนยันใน MetaMask
3. ยอดจะปรากฏใน **ยอดเงินที่ถอนได้**
4. กด **ถอนเข้า Wallet** แล้วยืนยันใน MetaMask เพื่อรับ ETH เข้าบัญชี B

การอนุมัติเป็นการจัดสรรยอด ต้องกดถอนอีกครั้งจึงจะได้รับเงินใน Wallet หากไม่ยอมรับยอดหัก ให้ใช้ขั้นตอนข้อพิพาทด้านล่าง

### A รับค่าเช่าและยอดหัก

สลับเป็น **A** แล้วกด **ถอนเข้า Wallet** เพื่อรับค่าเช่าและยอดหักที่ได้รับอนุมัติ หากจ่ายค่าเช่า 0.001 ETH หนึ่งครั้งและอนุมัติหัก 0.0005 ETH จะถอนได้รวม 0.0015 ETH เมื่อยังไม่เคยถอนก่อนหน้า

## 7. กรณีมีข้อพิพาท

1. หลังสัญญาสิ้นสุด ใช้ **A หรือ B** เปิดสัญญาที่ยังไม่ปิด จะเปิดข้อพิพาทก่อนหรือหลังส่งผลตรวจก็ได้
2. ที่ **เปิดข้อพิพาท** กรอกเหตุผล เช่น “ไม่ยอมรับยอดหัก ขอให้พิจารณาความเสียหาย”
3. กด **ส่งข้อพิพาท** แล้วยืนยันใน MetaMask สถานะจะเป็น **อยู่ระหว่างพิจารณา**
4. สลับเป็น **C — ผู้ชี้ขาด** เชื่อม MetaMask และเปิดสัญญาที่มีข้อพิพาท
5. ใน **ตัดสินข้อพิพาท** ใส่ **ยอดอนุมัติให้หัก (ETH)** เช่น `0.0003` และกรอก **คำตัดสินและเหตุผล**
6. กด **บันทึกผลและจัดสรรเงิน** แล้วยืนยันใน MetaMask
7. สลับเป็น **B** เปิดสัญญา ตรวจคำตัดสิน แล้วกด **ถอนเข้า Wallet** ตัวอย่างประกัน 0.002 ETH หัก 0.0003 ETH จะคืน 0.0017 ETH
8. สลับเป็น **A** กด **ถอนเข้า Wallet** เพื่อรับยอดหัก 0.0003 ETH รวมกับค่าเช่าที่ยังไม่ได้ถอน

## 8. หากไม่พบปุ่มหรือข้อมูล

| อาการ | วิธีตรวจ |
| --- | --- |
| ไม่เห็นสัญญา | ใช้ A เจ้าของห้องหรือ B ที่ระบุในสัญญา ตรวจ Contract Address แล้วกดโหลดข้อมูลล่าสุด ส่วน C เห็นรายการข้อพิพาทที่เกี่ยวข้อง |
| ไม่เห็นปุ่มฝาก | ต้องเป็น B ทั้งสองฝ่ายยืนยันแล้ว ยังไม่ฝาก และสัญญายังไม่หมดเวลา |
| ไม่เห็นปุ่มจ่ายค่าเช่า | ต้องเป็น B ฝากเงินประกันแล้ว และอยู่ในช่วงเวลาเช่า |
| ไม่เห็นแบบฟอร์มตรวจห้อง | ต้องเป็น A สัญญายังอยู่ในสถานะกำลังเช่าและหมดเวลาแล้ว กดโหลดข้อมูลล่าสุด |
| ไม่เห็นปุ่มชี้ขาด | ต้องเป็น C ที่ตั้งไว้ใน Smart Contract และสัญญาเปิดข้อพิพาทแล้ว |
| ไม่พบ Smart Contract | เลือก Sepolia และใส่ Contract Address ให้ถูก อย่าใส่ Wallet Address |
| อนุมัติคืนแล้วแต่เงินไม่เข้า | กดถอนเข้า Wallet และยืนยันธุรกรรม พร้อมมี ETH สำหรับ gas |
| MetaMask แจ้งยกเลิก | กดทำรายการใหม่เมื่อพร้อม แล้วรอธุรกรรมสำเร็จก่อนขั้นตอนถัดไป |

ยอด ETH หลังถอนอาจต่างจากยอดรับสุทธิที่คำนวณ เพราะบัญชีที่ส่งธุรกรรมต้องจ่าย gas ข้อมูลที่บันทึกบนเครือข่ายเป็นสาธารณะ ควรใช้ข้อมูลสมมติในการสาธิต
